## 背景・動機

> **取り下げ（2026-09-18）**: 依存先の REQ-148（Web UI 3 ペイン化）が取り下げられ、Web UI は REQ-168（GUI モード）の共有コンポーネントをホストする形に統合された。GUI 側でフォーマット定義エディタを扱う場合は REQ-168 の後続として改めて起票する。

フォーマット定義（.bdef.yaml）の作成は現在テキストエディタで行い、CLI でデコードして確認するサイクルである。Web UI にフォーマット定義のエディタを組み込むことで、定義の編集とデコード結果のプレビューを同一画面で行えるようになる。

ブラウザ上で完結する「フォーマット定義 playground」として、学習・実験・共有の用途に適する。
