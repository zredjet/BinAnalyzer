## 背景・動機

`schema` サブコマンドは Mermaid / DOT でフォーマット定義の struct 参照関係を出力できるが、GUI モード（REQ-168）にはモックアップの「スキーマ図」ボタンに相当する表示がない。定義を読みながら構造の全体像を把握するために、GUI 内で図を表示したい。

## 機能要件

### 追加する機能

- [ ] コマンドバーに「スキーマ図」ボタンを追加し、右ペインに「スキーマ」タブを開く
- [ ] `MermaidSchemaFormatter` の出力を描画する。描画は SVG をクライアント側で生成（Mermaid の JS ライブラリを `wwwroot` に同梱、外部 CDN に依存しない）
- [ ] 図のノードをクリックすると、その struct の最初の出現ノードをツリーで選択し、定義ビューでその struct へジャンプ
- [ ] 選択中ノードの struct を図上で強調

### 変更しないもの（スコープ外）

- DOT / Graphviz による描画（Mermaid のみ）
- 図のレイアウト編集

## 受入条件

1. [ ] PNG 定義でスキーマタブに struct 数と同数のノードが描画されること
2. [ ] 図のノードクリックでツリー選択が変わること（bUnit では JS 相互作用をスタブしてイベント経路を検証）
3. [ ] Mermaid ライブラリがオフラインで読み込まれること（デスクトップの埋め込み配信を含む）
4. [ ] 既存テストが全て通過すること（`dotnet test` 全通過）
