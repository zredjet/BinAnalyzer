## 背景・動機

Web UI（Blazor WebAssembly）は完全にクライアントサイドで動作するため、PWA（Progressive Web App）化に適している。PWA 化により、オフラインでの利用、ホーム画面へのインストール、高速な再起動が可能になる。

バイナリ解析はネットワーク接続不要な作業であり、オフライン対応の恩恵が大きい。

## 機能要件

### 追加する機能

- [ ] Service Worker によるオフラインキャッシュ
- [ ] Web App Manifest（インストール可能化）
- [ ] アプリアイコン・スプラッシュスクリーン
- [ ] キャッシュ更新戦略（新バージョンの通知と更新）

### 変更する既存機能

- [ ] `index.html` — manifest リンク、Service Worker 登録追加

### 変更しないもの（スコープ外）

- プッシュ通知
- バックグラウンド同期

## 受入条件

1. [ ] オフライン状態で Web UI が動作すること
2. [ ] ブラウザの「インストール」プロンプトが表示されること
3. [ ] インストール後にスタンドアロンウィンドウで起動できること
4. [ ] 新バージョン公開時にキャッシュが更新されること
5. [ ] 既存テストが全て通過すること（`dotnet test` 全通過）
