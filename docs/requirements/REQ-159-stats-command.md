## 背景・動機

バイナリファイルの解析において、フィールド値の分布やエントロピーなどの統計情報は、フォーマットの理解やデータ品質の評価に役立つ。現在はデコード結果をツリーや JSON で表示するのみで、統計的な分析機能がない。

例えば、MP3 ファイルの全フレームのビットレート分布や、ZIP ファイル内の圧縮率一覧など、フォーマット横断的な統計を簡便に取得できるコマンドが望まれる。

## 機能要件

### 追加する機能

- [ ] `binanalyzer stats <file> -f <format>` サブコマンド
- [ ] ファイルサイズ、デコード成功率（デコード済みバイト / 総バイト）
- [ ] フィールド値の分布（繰り返し構造体内の同名フィールドの集計）
- [ ] バイトエントロピー計算
- [ ] フィールド型別のバイト数集計
- [ ] `--format json` オプションで機械可読な出力

### 変更する既存機能

- [ ] なし

### 変更しないもの（スコープ外）

- 統計結果のグラフ表示（テキストベースの集計のみ）
- 複数ファイルの横断集計

## 受入条件

1. [ ] `binanalyzer stats` でファイルサイズとデコード成功率が表示されること
2. [ ] 繰り返しフィールドの値分布が集計されること
3. [ ] バイトエントロピーが計算・表示されること
4. [ ] `--format json` で JSON 出力が得られること
5. [ ] 既存テストが全て通過すること（`dotnet test` 全通過）
