## 背景・動機

> **取り下げ（2026-09-24）**: GUI 向けの同等の要望 REQ-174（ブックマークと注釈）があり、対話的な機能は GUI に集める。TUI には検索（`/`、`n` / `N`）が既にある。フィルタ・コピーが GUI にも必要なら REQ-174 に含めるか別途起票する。

TUI（対話型ターミナル UI）では3ペインレイアウトでバイナリ構造を閲覧できるが、大きなファイルの解析時に特定フィールドの記録・検索・データ取得が不便である。

ブックマーク（注目フィールドのマーク）、フィルタ（条件によるフィールド絞り込み）、コピー（選択フィールドの値をクリップボードにコピー）を追加することで、TUI の実用性を向上させる。

## 機能要件

### 追加する機能

- [ ] ブックマーク — フィールドノードにマークを付け、ブックマーク一覧からジャンプ
- [ ] フィルタ — フィールド名・型・値による絞り込み表示
- [ ] コピー — 選択フィールドの値（または hexdump 範囲）をクリップボードにコピー
- [ ] ブックマーク一覧パネル（トグル表示）

### 変更する既存機能

- [ ] TUI キーバインド — ブックマーク/フィルタ/コピーのショートカット追加
- [ ] TUI ツリービュー — フィルタ適用時の表示制御

### 変更しないもの（スコープ外）

- ブックマークの永続化（セッション内のみ）
- 正規表現によるフィルタ（文字列部分一致のみ）

## 受入条件

1. [ ] キーバインドでフィールドにブックマークを付与/解除できること
2. [ ] ブックマーク一覧からジャンプできること
3. [ ] フィルタ入力でツリーが絞り込まれること
4. [ ] 選択フィールドの値をクリップボードにコピーできること
5. [ ] 既存テストが全て通過すること（`dotnet test` 全通過）
