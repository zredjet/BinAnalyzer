## 背景・動機

大きなファイルの解析では「気になったフィールドに印を付けて後で戻る」操作が必要になる。TUI 向けには REQ-161（ブックマーク・フィルタ・コピー）が draft で存在する。GUI モード（REQ-168）の左ナビにもモックアップ由来の「ブックマーク」項目があり、同じ概念を GUI で提供する。

## 機能要件

### 追加する機能

- [ ] ノードのブックマーク追加 / 解除（インスペクターのボタン、ツリーの右クリック、`Ctrl+D`）
- [ ] 左ナビ「ブックマーク」でブックマーク一覧ペインを開く。パス・値・メモを表示し、クリックで選択
- [ ] ブックマークにメモ（1 行）を付けられる
- [ ] ブックマークをファイルパスと紐付けて永続化（デスクトップ: ユーザー設定ディレクトリの JSON、Web: `localStorage`）
- [ ] ブックマーク一覧を JSON / CSV でエクスポート

### 変更しないもの（スコープ外）

- ブックマークの共有・同期
- 範囲（バイト区間）に対するブックマーク（ノード単位のみ）

## 受入条件

1. [ ] ブックマークを追加すると一覧に現れ、クリックでそのノードが選択されること
2. [ ] 再デコード後もパスで復元されること（構造が変わり消えた場合は「見つかりません」表示）
3. [ ] 同じファイルを開き直すとブックマークが復元されること（ホストごとの永続化）
4. [ ] エクスポート結果にパス・値・メモが含まれること
5. [ ] 既存テストが全て通過すること（`dotnet test` 全通過）
