## 背景・動機

圧縮フィールド（`compression:`）の展開後の構造はツリーで辿れるが、展開後のノードは「ストリーム空間」のオフセットを持つため、GUI（REQ-168）のヘックスビュー・構造マップには対応するバイトが表示されない（`NodeIndex.IsInFileSpace = false`）。モックアップの InfoBar にある「展開ストリームを開く」に相当する、展開後バイト列を対象にしたビューが必要。

## 機能要件

### 追加する機能

- [ ] InfoBar とインスペクターに「展開ストリームを開く」ボタン。圧縮ノードを選択中のみ有効
- [ ] 展開ストリームを新しいタブとして開く（タブ名 `image.png › chunks[3].data`、親タブへ戻るリンク）。データは `DecodedCompressed.RawDecompressed`、ルートは `DecodedContent`
- [ ] 展開タブでもヘックス・ツリー・インスペクター・構造マップ・検索が通常どおり動作
- [ ] 親タブでストリーム内ノードを選択すると、ヘックスには圧縮フィールド全体を薄く強調し、ステータスに「展開ストリーム内」と表示

### 変更しないもの（スコープ外）

- 展開ストリーム上の編集・再圧縮（REQ-169 の後続）

## 受入条件

1. [ ] `RawDecompressed` を持つ圧縮ノードから展開タブを開け、`DecodedContent` の葉がヘックスに色分け表示されること
2. [ ] 展開タブのファイルサイズ・フォーマット表示が展開後のものになること
3. [ ] 親タブでストリーム内ノードを選択したとき例外にならず、圧縮フィールド全体が強調されること
4. [ ] 既存テストが全て通過すること（`dotnet test` 全通過）
