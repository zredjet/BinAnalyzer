## 背景・動機

REQ-101 で構造化 diff が CLI 出力として実装済みである。しかし、TUI（対話型ターミナル UI）では2つのファイルを並列に開いて構造差分を対話的に閲覧する機能がない。

TUI 内で diff 機能を提供することで、差分のあるフィールドへのナビゲーション、hexdump の対比表示など、対話的な差分分析が可能になる。

## 機能要件

### 追加する機能

- [ ] TUI で2ファイルの並列表示レイアウト（左右分割）
- [ ] ツリービューでの差分ハイライト（追加/削除/変更の色分け）
- [ ] 差分フィールド間のジャンプナビゲーション（次の差分 / 前の差分）
- [ ] hexdump ペインの同期スクロール
- [ ] CLI 起動オプション: `binanalyzer tui --diff <file1> <file2> -f <format>`

### 変更する既存機能

- [ ] TUI レイアウト — 2ファイル並列モード追加

### 変更しないもの（スコープ外）

- 3ファイル以上の diff
- 異なるフォーマット間の diff

## 受入条件

1. [ ] `binanalyzer tui --diff` で2ファイルが左右に並列表示されること
2. [ ] 差分のあるフィールドが色分けされていること
3. [ ] 差分ジャンプのキーバインドで次/前の差分に移動できること
4. [ ] hexdump が同期スクロールすること
5. [ ] 既存テストが全て通過すること（`dotnet test` 全通過）
